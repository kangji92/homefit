# 코드 리뷰 체크리스트

AI 에이전트의 자기 리뷰와 사람 리뷰에 공통 사용.

## 설계 정합성 (Homefit 우선)

- [ ] 변경이 **설계 문서(`docs/design/`)와 일치**하는가. 불일치 시 **문서를 먼저 수정**했는가 (CLAUDE.md Development Workflow).
- [ ] 적합도 점수가 **결정적 계산**인가. AI/임의 생성 점수가 아닌가.
- [ ] 후보 정렬이 **`sortByFit` 규칙**(통과 후보 우선)을 따르는가. 탈락 후보가 상위로 뜨지 않는가.

## 정확성

- [ ] 요구사항을 모두 충족하는가(누락·초과 없음).
- [ ] 엣지 케이스(빈 값·비활성·에러·정규화 경계값)를 처리하는가.

## 표준 준수

- [ ] `component-authoring.md` 준수(props 타입 명시, `any` 없음, Server/Client 경계 적절).
- [ ] 접근성(시맨틱 태그·role·label, jsx-a11y 통과).
- [ ] 테스트 동반 & `pnpm test` 통과(`testing.md`).
- [ ] 데이터 접근이 **repository 인터페이스**를 통하는가(직접 mock/Supabase 결합 금지).

## 품질

- [ ] 불필요한 복잡도·중복 없음(DRY, YAGNI — 이른 공통화 금지).
- [ ] 네이밍이 의도를 드러내는가.
- [ ] 부수효과가 적절히 분리되어 있는가.
