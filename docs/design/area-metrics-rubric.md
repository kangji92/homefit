# AreaFit 지역지표 채점 루브릭

개발 예정지(Area)의 `areaMetrics`(0~100)에 **근거**를 부여하기 위한 채점 기준.
숫자가 임의값이 아니라 관찰 가능한 사실에 매핑되도록 한다. 일부 축은 실수치로
결정적 환산하고, 나머지는 이 루브릭 기준의 판단 + 지역별 `metricsBasis`로 근거를
표기한다. (AreaFit 점수는 여전히 결정적 — `domain-model-v2.md` §3.2)

## 축별 기준

| 축 | 0~100 의미 | 근거(관찰 대상) |
|----|-----------|-----------------|
| **supply**(공급) | **실 계획 세대수로 결정적 환산**(아래 공식) | 공식 발표 세대수 |
| transitPlan(교통) | 확정 광역철도 등급 | GTX 노선·급행철도·서울 접근시간. GTX 2개+ 또는 서울 20분대≈85+, GTX 1개≈75, 광역버스/S-BRT≈60~68, 미확정≈50 |
| plannedInfra(계획 인프라) | 자족용지·생활인프라 성숙도 | 자족용지 비율, (재건축은) 기존 인프라 성숙도. 도심 재정비 80+, 신도시 자족 70~80, 소규모 60~68 |
| futurePotential(미래가치) | 개발 확정도·호재 | 교통 호재·산업 배후(반도체 등)·재건축 프리미엄. 확정+호재 80+, 계획 단계 70~78 |
| environment(주거환경) | 녹지·수변·쾌적성 | 한강/호수/녹지 인접 78+, 일반 66~74 |

**supply·education은 AreaFit 점수에서 제외**(표시용). transitPlan은 commute
우선순위에 매핑(§3.2). 즉 supply를 실수치화해도 점수엔 영향 없고, "공급 규모"
표시 지표가 근거 있는 값이 된다.

## supply 결정 공식

```
supplyScore(계획세대수 h) = clamp( round(38 + (h/10000) × 7.2), 35, 98 )
```
예: 왕숙 8.0만→96 · 광명시흥 6.7만→86 · 교산 3.7만→65 · 계양 1.8만→51 ·
장위 0.59만→42 · 1기재건축 선도지구(순증 적음)→40대.

## 표기

- 각 Area에 `metricsBasis`(핵심 근거 한 줄) + `plannedHouseholds`(실 세대수).
- 화면: 지역 지표 아래 "점수 근거" 노출 + 본 루브릭 참조. supply는 "실 계획
  세대수 기준"으로 표기.
- 값은 발표 자료 기반 추정 판단이며, 최종은 공식 지구계획으로 확인(고지 유지).
